# الملفات المعدّلة

## ١. `src/index.css`

### أ. متغيرات جديدة ومحذوفة (`:root`)

**محذوف:**
```css
--white: #FFFFFF;      /* ما كان مستعمل بأي مكان */
--text-margin: auto;   /* "auto" مش قيمة تصميمية، ما بتنفع كرمز */
```

**مضاف:**
```css
/*----------------------font sizes----------------------*/
--font-sm: 1.05rem;
--font-md: 1.2rem;
--font-lg: 1.5rem;
```

**السبب:** كان الملف بيستعمل `var(--gap-md)` كحجم خط بمكانين. الرموز لازم تكون مفصولة حسب وظيفتها — مسافات لحالها وأحجام خط لحالها. غير هيك، يوم بدك تعدّل المسافات بيتغير حجم الخط معها.

> `--font-sm` لسا غير مستعملة — تركتها جاهزة للأقسام الجاية.

### ب. الهيدر

```css
header {
  background-color: var(--broun);   /* كان var(--light-broun) */
  z-index: 10;                      /* مضاف */
}
```

**السبب (اللون):** التباين بين `#F0E4D8` و `#8C6448` كان **4.17**، وحد WCAG AA للنص العادي هو **4.5**. مع `#7A5236` صار **5.44** ✅. وهذا كمان صار يستهلك `--broun` اللي كانت معرّفة وغير مستعملة.

**السبب (`z-index`):** الهيدر `position: sticky`. بدون `z-index` ممكن تمر عناصر موضعية من فوقه لما تضيف أقسام جديدة.

```css
header a {
  font-size: var(--font-lg);   /* كان var(--gap-md) */
}
```

القيمتين متساويتين (١.٥rem) — **الشكل ما تغيّر**، الرمز بس صار يعبّر عن وظيفته.

### ج. لوجو الهيدر: `h1` صار `span`

```css
header .logo {          /* كان header h1 */
  margin: var(--gap-sm);
  color: var(--text-on-dark);
  font-size: 2rem;       /* مضاف */
  font-weight: bold;     /* مضاف */
}
```

**السبب:** كان في `<h1>` مرتين بالصفحة (اللوجو والهيرو). الصفحة لازم يكون فيها `h1` واحد — هو عنوان الصفحة الفعلي، يعني عنوان الهيرو. الـ headings بتبني خريطة الصفحة لقارئات الشاشة ولمحركات البحث.

السطرين المضافين ضروريين لأن `<span>` ما بياخد الحجم والوزن الافتراضيين تبع `<h1>` (اللي هي `2em` و `bold`) — بدونهم كان شكل اللوجو رح يصغر.

### د. `#root`: من grid لـ flex

```css
#root {
  min-height: 100dvh;
  display: flex;              /* كان display: grid */
  flex-direction: column;     /* كان grid-template-rows: auto 1fr auto */
}
```
```css
#hero {
  flex: 1;                    /* مضاف — بيقوم مقام 1fr */
}
```

**السبب:** `position: sticky` على عنصر شبكة (grid item) بينحصر بحدود منطقته بالشبكة. منطقة الهيدر كانت صف `auto` بطول الهيدر بالضبط، يعني صفر مساحة يتحرك فيها → الهيدر كان بيروح مع السكرول رغم `position: sticky`.

بالـ flex، عنصر الـ flex ما بينحصر بمنطقة صغيرة، فالـ sticky بتشتغل على طول الصفحة. و `flex: 1` على الهيرو بتعمل نفس شغلة `1fr` — بتاخد المساحة المتبقية فالفوتر بيضل تحت.

> **لما تضيف قسم ثاني:** لازم تلف الأقسام بـ `<main>` وتنقل `flex: 1` من `#hero` لـ `main`.

### هـ. الهيرو

```css
#hero {
  background-color: var(--broun);   /* كان var(--light-broun) — نفس سبب الهيدر */
  font-size: var(--font-lg);        /* كان var(--gap-md) — نفس القيمة، رمز أصح */
}
```

```css
#hero h1 {                                  /* قاعدة جديدة كلياً */
  font-size: clamp(1.8rem, 5vw, 3rem);
  line-height: 1.3;
}
```

**`clamp(الحد-الأدنى، المفضّل، الحد-الأقصى)`** — حجم خط متجاوب بدون media query. `5vw` معناها ٥٪ من عرض الشاشة، بس محصورة بين ١.٨rem و ٣rem. يعني على الموبايل ما بينزل تحت ١.٨ وعلى الشاشة الكبيرة ما بيطلع فوق ٣.

`line-height: 1.3` لأن `1.7` الموروثة من الـ `body` كتير للعناوين الكبيرة — كل ما كبر الخط، قلّت الحاجة لتباعد الأسطر.

```css
#hero img {
  width: 100%;         /* كان 60% */
  max-width: 420px;    /* مضاف */
}
```

**السبب:** `60%` كانت ثابتة بغض النظر عن حجم الشاشة. على الموبايل لما ينكسر العمودان، ٦٠٪ من عمود ضيق بتطلع صورة صغيرة جداً. النمط الصح: خليها تملا الحاوية (`100%`) مع سقف يمنعها تتضخم على الشاشات الكبيرة (`max-width`).

### و. الأزرار

القاعدة المشتركة صارت تحمل كل اللي مشترك:

```css
.hero-btn button {
  font-size: var(--font-md);   /* كان font-size: large */
  font-family: inherit;        /* مضاف */
  padding: var(--gap-sm) var(--gap-md);
  border-radius: 8px;
  cursor: pointer;                                    /* منقولة من القاعدتين */
  transition: background-color 0.2s, color 0.2s;      /* منقولة من القاعدتين */
}
```

- `large` كلمة مفتاحية وسط ملف كله `rem` — عدم اتساق.
- `font-family: inherit` — الأزرار ما بترث خط الصفحة تلقائياً، بتاخد خط النظام. الفرق بيبان بالعربي.
- `cursor` و `transition` كانت مكررة بالقاعدتين، فنقلتها للمشتركة.

ومحددات الـ `id` صارت كلاسات:

```css
#menubtn      →  .btn-primary
#location-btn →  .btn-outline
```

**السبب:** باقي الملف كله كلاسات، والـ `id` أعلى أولوية (specificity) بكتير فبتصعّب التعديل لاحقاً. وكمان `.btn-primary` / `.btn-outline` أسماء بتوصف **الدور** مش المكان، فبتقدر تعيد استعمالها بأي قسم.

### ز. قسم responsive جديد

```css
/*----------------------responsive----------------------*/
@media (max-width: 700px) {
  #hero-text {
    margin-inline-end: 0;
  }
}
```

**السبب:** `margin-inline-end: var(--gap-lg)` على `#hero-text` مقصودة تقرّب النص من الصورة لما يكونوا جنب بعض. لما تنكسر الأعمدة على الموبايل ما بيضل في صورة جانبها، فالإزاحة بتصير خلل بصري — نص مزحزح بدون سبب.

## ٢. `src/Home.jsx`

```jsx
<img src={HeroPic} alt="فنجان قهوة ساخنة بجانب حبوب البن" />
```

كان `alt=""`. الـ `alt` الفاضي معناه رسمياً "صورة زخرفية، تجاهلوها" — وصورة الهيرو مش زخرفية.

```jsx
<button className="btn-primary">المنيو</button>
<button className="btn-outline">موقعنا</button>
```

كانوا `id='menubtn'` و `id='location-btn'`.

بالإضافة لضبط المسافات البادئة (indentation) — تغيير شكلي بحت، ما بيأثر على النتيجة.

# ملاحظات ما انطبّقت (متروكة لسامر)

1. **`<main>`** — لازم تلف الأقسام فيه قبل ما تضيف القسم الثاني، وإلا `flex: 1` بتنطبق على الهيرو لحاله.
2. **ترتيب `index.css`** — القواعد مش مرتبة حسب ترتيب الصفحة (`#root` و `.social` متناثرين وسط قسم الفوتر، والهيرو بالآخر).
3. **`--fotter-bg`** — خطأ طباعة، الصح `--footer-bg`.
4. **`--broun` / `--light-broun` / `--dark-broun`** — الصح `brown`.
5. **`--text-on-light`** — معرّفة وغير مستعملة، بتصير لازمة لما تضيف قسم بخلفية فاتحة.
6. **روابط السوشال بالفوتر** — بدون `aria-label` وبدون `rel="noopener noreferrer"`.
7. **روابط الهيدر** — `href="#"` بتشير لأقسام لسا غير موجودة (قصتنا، التواصل، app).
