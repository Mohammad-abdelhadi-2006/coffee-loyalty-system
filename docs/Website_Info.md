# website

## Visual Identity & Color Palette

The design reflects a warm, premium coffee shop ambiance using a modern dark theme:

- **Primary Background:** Rich Dark Espresso for a sleek, comfortable reading experience.
- **Header & Structural Elements:** Warm Roasted Coffee .
- **Accent & Buttons:** Caramel & Cream to highlight key actions, point balances, and interactive buttons.
- **Typography:** Clean, modern Sans-serif fonts for clear readability across all devices.

## Page Structure & Scope

The website consists of 3 dedicated pages:

### 1. Home Page

A concise, fast-loading landing page:

- **Hero Section:** High-quality visuals showcasing the brand’s coffee experience.
- **About Us:** A brief intro to the shop's identity and ambiance.
- **Best Sellers & Special Offers:** Features top-selling drinks with an integrated banner for current promotions (e.g., Free Cookie Offers).
- **Get Mobile App:** A compact section prompting users to download the mobile application and start earning reward points.
- **Footer:** Social media links, operational hours, and documentation rights.

### 2. Full Menu Page

A dedicated page displaying the complete catalog:

- **Categories:** Hot Drinks, Cold Drinks, Bakery & Desserts.
- **Item Details:** Available sizes, pricing, and reward points earned per purchase.

### 3. Contact & Location Page

Handles customer inquiries and location details:

- **Interactive Map (Google Maps):** Displays exact branch location and working hours.
- **Feedback & Complaint Form:** Enables customers to select their message category (Complaint, Suggestion, Inquiry) and submit directly.
- **Direct Channels:** WhatsApp and phone contact info.

## Navigation Bar (Navbar Component)

- **Brand Logo:** Quick link to return home.
- **Page Links:** `Home` | `Menu` | `Find Us & Contact`.
- **Controls:** Language Switcher (`EN / AR`) + CTA button for App Download.
